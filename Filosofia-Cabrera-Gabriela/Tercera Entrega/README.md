# Filosofía: Tercera entrega

Docente: Gabriela Cabrera

Consigna: presentar la primera versión escrita de la fundamentación del
proyecto de egreso. Solo un integrante del grupo debe enviar una copia en
formato digital.

Una fundamentación es el texto que justifica y sostiene la idea central de
un proyecto, explicando por qué es relevante, viable o valioso. En esta
etapa se espera que contenga:

- [ ] Una tesis clara: la idea principal que sostiene el proyecto
- [ ] Al menos tres o cuatro premisas que respalden y sostengan la tesis
      (razones que justifiquen esa idea)
- [ ] Redacción clara, coherente y ordenada
- [ ] Extensión de una a dos páginas completas

Esta entrega será revisada y luego se podrá mejorar a partir de las
recomendaciones.
